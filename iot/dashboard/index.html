    The rain tank has an ultrasonic sensor at the top measuring the distance down to the water. Set the tank height (sensor to floor), the gap left when full, and the surface area, which turns the level into litres (1 cm over 1000 cm² = 1 L; round tank: 0.785 × diameter²). When the level reaches the alert level, the Pi and this page ask you to release the water.

    Farm setup for today's advice. Measure a pump's flow by timing how long it takes to fill a 10 L bucket.

    Pump direction. Both pumps run from the motor driver (keep the ENA / ENB jumpers on). A DC pump spinning backwards still runs but pumps weakly: reverse it here.

    Wiring test: one driver input HIGH for 5 s, all others LOW. IN1 / IN2 should spin pump 1 (opposite ways), IN3 / IN4 pump 2.

    Mega ↔ Pi over USB (/dev/ttyACM0 at 115200 baud). Ultrasonic sensor: VCC to 5V, GND to GND. Pumps run from the motor driver: its 12V input from the pump supply, its GND joined to the Mega GND. Never power a pump from the Mega's 5V pin.
